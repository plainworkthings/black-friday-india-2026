# Black Friday 2026 — India & Bangalore

Static page of Black Friday 2026 clothing and electronics offers in India and Bangalore. Every price, date, discount and link is taken from the 25 Nov 2026 source list. Offers change, so check the retailer site before buying.

Open `index.html` in a browser, or serve this folder with any static file server.

GitHub Pages: https://plainworkthings.github.io/black-friday-india-2026/

The site is published by `.github/workflows/pages.yml` on every push to `main`. In the repository settings, Pages → Build and deployment → Source should be **GitHub Actions**.
